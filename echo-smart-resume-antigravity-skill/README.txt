# ECHO → Smart Resume AI Antigravity skill

This archive contains a workspace-level Antigravity skill:

`.agents/skills/echo-smart-resume-integration/SKILL.md`

Extract the `.agents` folder into the root of `D:\projects\builder-github`.

Then reload skills or restart Antigravity. Invoke the skill with:

`/echo-smart-resume-integration`

The skill is intentionally read-only at first: it audits both repositories and their Git worktrees before making changes. It also requires license review before copying ECHO source or assets.
